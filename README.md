## ⚙️ الميزات الأساسية

- **منشن لجميع الأعضاء** باستخدام الأمر `.tagall`
- **تحكم خاص بالمشرفين** (فقط مشرفي المجموعات يمكنهم استخدام بعض الأوامر)
- **ألعاب تفاعلية** مثل إكس أوتو (Tic-Tac-Toe) للتفاعل داخل المجموعة
- **تحويل النص إلى كلام** باستخدام `.tts`
- **صنع الملصقات** باستخدام `.sticker`
- **كشف الروابط وحظرها** لحماية المجموعة
- **نظام تحذيرات وإدارة الأعضاء** بتحكم كامل للمشرفين

## 📖 نبذة عن البوت

يساعد بوت Chaos_bot مشرفي المجموعات من خلال تزويدهم بالأدوات اللازمة لإدارة مجموعات واتساب الكبيرة بكفاءة. يستخدم البوت مكتبة Baileys للتفاعل مع واجهة WhatsApp Web ويدعم ميزات الأجهزة المتعددة.

البوت خفيف الوزن ويمكن تخصيصه بسهولة لإضافة المزيد من الأوامر وفقاً لمتطلباتك.

## 🛠️ الإعداد والتثبيت

### المتطلبات الأساسية

- تثبيت Node.js على نظامك
- تثبيت Git (لاستنساخ المستودع)

### خطوات التثبيت خطوة بخطوة

1. **استنساخ المستودع:**

    ```bash
    git clone [https://github.com/a18392428-ai/Chaos_bot.git](https://github.com/a18392428-ai/Chaos_bot.git)
    cd Chaos_bot
    ```

2. **تثبيت الحزم المطلوبة:**

    ```bash
    npm install
    ```

3. **تشغيل البوت:**

    ```bash
    npm start
    ```
